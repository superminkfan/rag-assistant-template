# StackOverflow answered questions KB

Combined raw local knowledge base for Apache Ignite 2 answered questions, primarily from StackOverflow.

## Files

- `answered-questions.combined.jsonl`: main JSON Lines database. One normalized record per answered StackOverflow question or closed commented GitHub issue.
- `manifest.json`: generation metadata and source record counts.

## Sources

The source dumps were merged into `answered-questions.combined.jsonl` and then removed to keep the repository compact.
